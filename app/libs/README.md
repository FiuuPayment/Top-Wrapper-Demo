# Put the ToP libraries here

Copy **all 4** files provided by Fiuu into this folder before you build:

```
app/libs/topnewroute-debug.aar
app/libs/topnewroute-release.aar
app/libs/mobile-pogengine.aar
app/libs/filter-ssmobile.jar
```

These `.aar` and `.jar` files are provided by Fiuu after registration. They are not in this repo. Gradle will fail if any of the four is missing.
